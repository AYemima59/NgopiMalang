# NgopiMalang — pratinjau website

Jalankan `Jalankan website.bat`, lalu buka http://localhost:8000 jika browser tidak terbuka otomatis. Alternatifnya, buka `index.html` langsung. Navigasi mengarah ke halaman Jelajahi, Detail coffee shop, Artikel, Favorit, dan halaman baca artikel.

## Catatan pratinjau

- Ini adalah website statis tanpa server. Favorit, laporan ramai/sepi, koreksi, dan usulan hanya tersimpan di browser/perangkat yang sedang dipakai.
- Data tempat, rating, harga, jam buka, foto, Wi-Fi, serta angka statistik yang mengikuti desain Stitch adalah konten contoh. Ganti dan verifikasi sebelum dipublikasikan.
- Gambar, font, ikon, dan Tailwind CSS dimuat dari layanan eksternal, sehingga koneksi internet diperlukan untuk tampilan penuh.
- Halaman detail saat ini merupakan contoh untuk Bataputih Coffee & Space. Hubungkan direktori ke backend sebelum menampilkan data kedai lain sebagai profil terverifikasi.


## Desain

Beranda dan halaman Jelajahi menggunakan dua desain Stitch terbaru yang kamu kirim. Halaman Detail, Artikel, Favorit, dan baca artikel dibuat dengan gaya visual yang diselaraskan ke desain Stitch terbaru.
